Description

A Java Swing desktop application for managing a pharmacy's medicines, suppliers, users, and sales.

 Features

- User login with role-based access (Admin / Cashier)
- Manage medicines, suppliers, and users
- Point of Sale (POS) with cart and receipt
- Sales reports
- Automatic stock reduction on sale

 Tech Stack

- Java 17
- Java Swing (GUI)
- MySQL 8.x
- mysql-connector-j-8.0.33

 Setup

1. Import `pims_db.sql` into MySQL.
2. Place `mysql-connector-j-8.0.33.jar` in the `lib/` folder.
3. Update `src/pims/db/DBConnection.java` with your MySQL credentials.
